# 2026-09-21 PO EV-77 J1/J2 Ruling

The final EPIC-14 card EV-77's two step-6 open-judgment items, ruled by `product-owner`
(job-8) in the [[2026-09-21-epic14-run-ledger]].

## J1 — the gateFail-tail sentence is IN

The reader-facing page reproduces the EV-75 migration `FAIL:` literal byte-for-byte, and that
literal deliberately omits `gateFail`'s standard "set a valid value or remove the key to use
the packaged default" tail (the advice is wrong for this key). The page must carry **one
sentence explaining the reason**, inside the migration paragraph. Unexplained, a reader who
knows the `gateFail` template reads it as truncation and may "fix" it by re-attaching advice
that breaks resolution. Page copy only; the source is not touched.

## J2 — docs cards ship mechanical pins in `test/`, not `council/validate.py`

The Acceptance "cited code paths resolve mechanically" is satisfied by bun tests, **T1 (cited-path
existence + index reach)** joining T2–T6 over the real `vault/wiki/*.md`. The proposed
`council/validate.py` home is rejected on four grounds:

1. `validate.py` is **packaged tooling** ([[non-clobbering-scaffold]] / [[council-update]]): a
   check keyed to `extensions/**` citations would hardcode this package's layout into every
   consumer repo, where a wiki citation resolves under the install clone — the consumer's wiki
   would go red for doing nothing wrong.
2. Extending it diverges the repo copy from `council/scaffold/council/validate.py` and rides
   the consent-gated refresh/semver surface.
3. Enforcement parity is exact: CI runs `bun test` and `validate.py` back to back, and neither
   `wiki-ingest.md` nor `wiki-lint.md` runs validate.py — so validate.py has no timing advantage
   when a wiki page is written; the merge gate is the moment, and `test/` is already in it.
4. `test/` only runs in a repo that always has `vault/`, so the vault-absent seam constraint
   disappears.

Precedent: `test/fllwup25-agents-page.test.ts` and `test/fllwup58-gates-backstop.test.ts` were
both shipped by docs cards; FLLWUP-25 recorded "consistency check under `test/`, not
`council/`". Consumer-repo protection is a **separate tooling-class card** (`FLLWUP-93`).
