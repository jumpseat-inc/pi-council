The README frames pi-council around the author's motivating question — *"How do
I get prompted instead of prompting?"* — and four reinforcing concepts:
**Prompt Then Get Prompted**, **LLM Wiki** (long-term memory for product-building),
**Board & Cards** (local kanban holding the source of truth), and **The Council**
(diverse LLM roles that prove positions with tests and code).

## Key content

- **Install** — `pi install git:github.com/jumpseat-inc/pi-council` (the repo
  moved from the earlier `tistaharahap` org). Default is user-scope
  (`~/.pi/agent/settings.json`, clone under `~/.pi/agent/git/…`); `-l` installs
  project-local (`.pi/settings.json`, `.pi/git/…`). Same package in both scopes
  → project entry wins.
- **`/council-init`** scaffolds the data layer **and** pins two project-local
  dependencies so teammates auto-install: the **superpowers** skills package and
  **`rpiv-ask-user-question`**. The council refuses to run without them
  ([[council-dependencies]]).
- **Seat → superpowers skill pointers** — owner, skeptic, council-runner,
  designer, principal, judge point at skills; consolidator/product-owner/steward
  rule on judgment and get none.
- **Commands table** — the council loop, board/feature/wiki commands, MCP, and
  **`/council-update`** (refresh packaged tooling; dry-run by default; never
  touches board/cards/wiki — [[council-update]]).
- **Seats table** — 9 seats and their roles ([[seats]]).
- **Theme customization** — an oh-my-pi dark/light pair (`pi-council-dark` /
  `pi-council-light`), recolored per-repo via the top-level `theme` key in
  `.council.json`; `variant` auto/dark/light; `vars`/`colors` overrides;
  live repaint on edit ([[council-theme]]).
- **Requirements** — pi with a configured provider (seats pin OpenRouter models
  by default); no specific language/runtime required (the scaffolded
  `preflight.sh` is repo-extensible); unknown seat model fails loudly.
- **Git: what to commit** — commit `.council.json`, `.pi/council/scaffold.json`,
  `.pi/settings.json`, `.pi/agents/`, `.pi/council/procedures/`,
  `.pi/council/model-floors.json`, `.pi/council/mcp.json`; ignore `.pi/git/`,
  `.pi/npm/`, `.pi/council/.pids.json`; secrets live user-global.
- **MCP** — Context7 and Tavily ship by default; `preflight.sh` requires each
  registered server authenticated and an OpenRouter key source ([[mcp-support]]).
- **Development** — `bun install` / `bun test` (≈101s) / `bunx tsc --noEmit` /
  `bun run smoke`; the live arms are offline faux-provider runs; integration +
  context7 probes are opt-in ([[test-suite-budget]], [[smoke-test]]).
