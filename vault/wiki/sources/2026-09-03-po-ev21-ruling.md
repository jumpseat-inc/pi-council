# PO EV-21 Ruling (2026-09-03)

Binds the four open-judgment items the EV-21 deliberation routed:

- **CONFIRM-1 — name**: `/council-leaderboard`. Write side is
  `/council-eval`, read side is `/council-leaderboard`; two verbs, two
  surfaces, no shadowing in the `/council-` namespace. Rejected:
  `/council-eval-results` (reads as a directory listing). Note: the
  packet's spec-text mention of a "procedure file" is a clerical slip —
  the surface is a code-registered command per deliberation convergence
  (reconciled explicitly in the EV-21 spec).
- **CONFIRM-2 — fold-in**: the landed `summarizeStore` version-blind key
  (skeptic-empirically confirmed: blended `mean=0.625` across rubric
  versions) is fixed **in EV-21**, in place, failing-test-first, additive
  `CellSummary` fields, single-version byte-identity preserved. Deciding
  fact: the same-function-both-sides byte-identity contract makes
  fixing only one side mechanically impossible; a version-aware wrapper
  would reintroduce two truths on one seam.
- **J-1 — copy**: column `σ`, not `VARIANCE` — "naming it VARIANCE while
  computing σ is a lie-of-imprecision"; four-state empty spectrum (A
  dir-missing / B gate-only-only / C n<2 / D length-majority) bound;
  TRIAGE tier phrases bound (`tied (±CI)` keeps its parenthetical —
  without it the tier reads as "the same number"); both slices default.
- **J-2 — smoke**: Phase 4 mandatory (Q3 precedent: "the first Council
  command without an end-to-end falsifier is a defect"); the optional
  fixture-bump+rerun is OUT of default scope (unit tests carry that
  correctness; documented as a one-PR escape hatch needing no fresh
  ruling).
- **J-3 — kind limitation**: kind resolves against the current fixture on
  disk; accepted with disclosure copy + `unknown` bucket. Store schema
  amendment rejected (divergent-payload throw on re-runs, no backfill).

The card acceptance says "variance" while the mechanism ships Bessel σ —
resolved by ruling, not silently: the intent is dispersion; σ is its
honest name. See [[cell aggregation]].
