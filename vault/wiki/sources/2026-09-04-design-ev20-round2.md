# EV-20 Designer Round 2 (2026-09-04)

The designer's own retraction is the artifact: the round-1 matrix
pseudo-row above the inline job tree is **dropped** because it would be a
second progress surface duplicating what the hub already shows — "never
show the same information twice; never add a surface that can lie about
the data."

The settled two-surface posture:

- **Widget/inline tree** (free, no new code) answers "what is active now".
- **Per-repeat `[council-eval]` transcript lines** answer "which repeat,
  durable, greppable" — harness-written verbs, no LLM prose.
- **Echo-then-run** stays as the pre-dispatch forcing function, naming
  taskId + fixtureVersion + models + repeat + totalRuns.
- **One shared pure renderer** (`aggregateCell`) consumed by both EV-20's
  summary and EV-21's leaderboard — the drift window closes structurally.

Also: the smoke-test escalation ("the first Council command without an
end-to-end falsifier is a defect") originates here and became the EV-20
Q3 ruling; 17 falsifiable predictions on file.
