> ⚠️ **Planned — EPIC-12 is `Backlog` as of 2026-09-20; nothing is shipped.**

When a person types `pi` at a terminal, the first thing they need to know is
what version of pi-council they are running. EPIC-12 adds a first-run banner
showing the running **version** and the **latest git hash**, so a bug report can
name an exact, checkoutable revision. Related to the release-tag discipline on
[[pi-council-overview]] (tags are the release record; the install may run a
commit ahead of the latest tag).
