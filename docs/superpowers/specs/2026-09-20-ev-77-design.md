## Deliverables

### 1. `vault/wiki/metered-deliberation-routing.md` — extended in place (no new page)

Structure (settled in rounds 1–2; operator-first per the designer's
converged ordering):

1. **Off-as-Deliberate callout** — bolded paragraph (blockquotes are
   reserved for status notes) naming the inverted reading: `off` routes
   every card to the full Deliberate panel (maximum scrutiny); the naive
   "off = less rigor" reading is wrong. Absent file / absent `gate` section
   / `gate: {}` resolve `off` byte-identically (`resolveRoute` → Deliberate,
   basis `gate mode off — no recorded decision`). Timing precision: the mode
   is read lazily at gate-tool-call time, so a flip is visible to the
   current dispatch's next gate read.
2. **Turning the gate on: `/council-gate`** — operator section: status read
   (zero tokens), one-token write ∈ `off|advisory|active`, more than one
   token = usage error; the command's copy lines reproduced byte-verbatim as
   shipped (`extensions/council-gate-cmd.ts`); the status literal names no
   file — the page supplies the `.council.json` location in prose; write is
   a byte-region splice with echo-then-run verification and a no-op line.
3. **Config surface** — the `.council.json` `gate` section and its mode
   values (`off`, `advisory`, `active`); what each mode does
   (off ⇒ full Deliberate routing; advisory ⇒ gate runs, result rendered
   informationally, never enforced; active ⇒ enforced).
4. **Migration note (EV-75)** — the legacy `council/gate/policy.json`
   `mode` key fails loud with the enriched migration line, reproduced
   byte-for-byte and cited as `extensions/gate.ts:186-189`, inside this
   paragraph, followed by J1's one-sentence gateFail-tail reason. `mode` is
   no longer an accepted `policy.json` key.
5. **Run-start preflight (EV-76)** — when the gate is on and no OpenRouter
   credential resolves, the run-start preflight fails loud: the FAIL line
   verbatim, both remediations, and the procedure pointers (council.md
   step 0; features-deliver.md Phase 0).
6. **Reading the `Mode: <mode> — <basis>` line** — `decisionLine` is the
   one formatter; an **emitter-keyed union table** of every distinct basis
   shape the code can emit, each beside its emitting function:
   - the `decide()` shapes at the skeptic-verified line cites
     (`extensions/gate.ts:624/643/653/671/678/684` — override; choice
     floor; score floor; noul; composite-vs-direct; composite-vs-verify
     arms, with real numeric examples lifted from `test/gate-decide.test.ts`
     and `test/gate-render.test.ts`) plus the fail-closed shape
     (`gate call failed: <reason>` from gate-run.ts). The table's row set is
     every distinct emitted basis shape the owner finds by reading those
     cites — derive it from the code, do not trust a count carried in the
     deliberation record; T3 pins the coverage.
   - gate-render's cells B and C literals (both are honest distinct states —
     cell C is IN);
   - gate-route's fallback/drift/disagreement strings described as
     **routing-read `RouteResult` bases that never reach `decisionLine`**.
7. **`callId: null` — the tool short-circuit** — not ledger corruption; the
   three-way disambiguation: cell B (`callId:null`, the call failed before
   recording) vs `matchedCallId` (the routing-read result's join field) vs
   cell C (a recorded callId matching no ledger line).
8. **Intake-recorded vs dispatch-re-checked** — intake records the route
   with `touchedFiles: []`; the dispatch re-check fires only when
   `route.source === "recorded" && route.mode !== "Deliberate"` — a recorded
   Direct card IS re-checked; a recorded Deliberate card never is; the
   re-check reads the observed numstat set and is escalation-only (a
   ratchet, never a demotion). Cite EV-69 for the re-check's origin.
9. **Names and mapping** — three-column vocabulary table: the jev model pin
   (`typesafe/jev-1.13`) ↔ the gate (operator term, R5) ↔ the decisions API
   (wire name). This table is the page's only `jev` occurrence.
10. **Thresholds** — referenced by pointer to the decision record (the
    decision's `decision.json` artifact), never inlined numerals.

Also on the page: **Residuals sweep** — the Residuals section must no longer
