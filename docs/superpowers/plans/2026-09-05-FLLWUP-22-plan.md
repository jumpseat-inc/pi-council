## The `scrollbarTrack` allowlist call (recorded discretion)

**Decision: `scrollbarTrack` JOINS `OPTIONAL_TOKENS`** in `extensions/seats.ts`. Rationale — the settled keep-allowlist rationale (Skeptic obj 5 CLOSED-GREEN) is: the allowlist is the consumer recolor contract; `VALID_COLOR_KEYS` throws on any unlisted key, `activateTheme` swallows the throw into a warning notify, and `setTheme` is never called — so an unlisted-but-legal token in `.council.json` **silently deactivates the whole theme**. `scrollbarTrack` is shell-valid on the 0.85.x band consumers actually install, so declaring it must not hit the swallowed throw. On 0.84.3 a declared `scrollbarTrack` is inert-by-construction (carried in the fg map; pi's 0.84.3 machinery never reads it — no throw, no deactivation, no visual effect). This matches the majority final's own corpus (owner 18.11 listed "add `scrollbarTrack` to `OPTIONAL_TOKENS`") and the consolidator's reading ("the allowlist-KEEP rationale extends to it"). The alternative (leave the allowlist at 4) is defensible but strictly weaker: it reintroduces the exact silent-deactivation hazard this card exists to avoid on the 0.85.x band. The change is the single sanctioned `seats.ts` touch (spec §4 discretion clause); the diff stays otherwise within the enumerated scope.

const PI_VERSION = (JSON.parse(fs.readFileSync(path.join(PI_PKG_ROOT, "package.json"), "utf-8")) as { version: string }).version;
function semverAtLeast(v: string, target: string): boolean {
	const a = v.split(".").map((n) => parseInt(n, 10));
	const b = target.split(".").map((n) => parseInt(n, 10));
	for (let i = 0; i < Math.max(a.length, b.length); i++) {

		const y = b[i] ?? 0;
		if (x !== y) return x > y;
