**Tech Stack:** bun:test, the existing EV-40 offline harness (`test/ev40-harness/`), python3 pty runner (stdlib only), real `Hub`/`job-retry.ts`/`retry.ts`/`parent-retry.ts`.

**Spec:** `council/cards/EV-41.md` (`goal`, `Intent`, `## Run record (features-deliver / EV-41)` §Step 7 — the card is the handoff; no design spec on the mechanical path).
