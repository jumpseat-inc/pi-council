# FLLWUP-45 — Navigator attempt-awareness Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A retried dispatch's attempt transcripts are reachable from the navigator (an inline `[/]` attempt cycler), tree selection survives attempt respawns (row key = job id), and the progress title names the attempt whose transcript is shown.

**Architecture:** Three identities, three variables — row key = `manifest.id` (job, stable across respawns), content key = `manifest.sessionId` (unchanged; drives `keyFor`/`tails`/`lastBlocks`), and a new widget-owned `attemptCursor` (never the controller row key). One pure browsable-attempt accessor (`browsableAttempts`) plus one pure attempt selector (`resolveAttempt`) in `extensions/runs.ts`; keys `[`/`]` widen `classifyProgressKey` additively and deliver through a new `attemptHost` seam mirroring `viewHost`.

**Tech Stack:** TypeScript (strict, bun), pi-tui (`matchesKey`), bun:test.

**Spec:** `docs/superpowers/specs/2026-09-17-FLLWUP-45-design.md` (settled; steps 1–6d rulings are binding).

## Global Constraints

- Row label stays `m.attempt` (pending ordinal) verbatim per EV-39 R4: `attempt ${m.attempt}/${maxAttempts}` gated `m.attempt > 1` (`navigator.ts:370-373`) — **no data-source flip**.
- `keyFor` (`navigator.ts:334-336`) stays `manifest.sessionId`; `tails`/`lastBlocks`/`tailRead` are never re-keyed onto the row key (Skeptic O4: a row-key-keyed tail freezes on attempt 1's file).
- Copy is ruled and exact — only two new user-visible strings:
  1. Progress-title fragment `· attempt ${k}/${maxAttempts}` — gate `m.attempt > 1` (step-6d ruling (i)).
  2. Header advertisement `· [/] attempt` inserted immediately after `↑↓ move` in the existing R-KEYMAP line — gate `browsableAttempts(m).length > 1` (step-6d ruling (ii)).
- All other strings byte-identical: row label (`attempt N/M`, pending ordinal), `retrying in Ns`, `The provider returned an error.`, `Retrying in 2s (attempt 2 of 3) — Esc to abort`, exhaustion string.
- Out of scope (do not fold in): `openTranscript` at `navigator.ts:869` (deferred to FLLWUP-4), the legacy-modal title suffix, FLLWUP-39's dispose-on-session-switch defect, new tree rows, a picker modal, a second transcript-view slot (the cycler reuses the single `viewFor` slot).
- Rename is `selectedSessionId` → `selectedRowKey` (step-6b (e) default) — mechanical, no assertion semantics move.
- Cycler: clamp, not wrap; no-op when `browsable.length <= 1`; no-op when effective `progressLines <= 1` (header suppressed); never mutates `controller.selectedRowKey`.
- Gates (authoritative for this repo; no DB/import/server gate): `bunx tsc --noEmit`, `bun test`, `python3 council/validate.py`. `COUNCIL_INTEGRATION=1` stays gated and is not run.
- Conventional Commits; tests in `test/` importing via relative `.ts` paths; filesystem-touching tests use `fs.mkdtempSync` dirs, never the real repo.
- Main checkout branch state is immutable; all work happens in `.worktrees/fllwup-45`.

```typescript
/** FLLWUP-45 — the attempts the navigator may browse: the settled prefix
 *  (attemptEntries) plus the live session when it has not settled yet. */
export function browsableAttempts(
	m: RunManifest,
): { attempt: number; sessionId: string }[] {
	const entries = attemptEntries(m);
	const live = { attempt: m.attempt ?? 1, sessionId: m.sessionId };
	return entries.some((e) => e.sessionId === live.sessionId) ? entries : [...entries, live];
}

/** FLLWUP-45 — pure attempt selector (the resolveAttemptFile seam Q3 named,
 *  returning the entry rather than a path so FLLWUP-4 can reuse it). */
export function resolveAttempt(
	entries: { attempt: number; sessionId: string }[],
	cursorSessionId?: string | null,
): { attempt: number; sessionId: string; index: number } {
	if (entries.length === 0) return { attempt: 1, sessionId: "", index: 0 };
	const idx = cursorSessionId != null ? entries.findIndex((e) => e.sessionId === cursorSessionId) : -1;
	if (idx >= 0) return { ...entries[idx]!, index: idx };
	const last = entries.length - 1;
	return { ...entries[last]!, index: last };
}
```

    ```typescript
    	 *  never the controller's row key. Clamp, not wrap; no-op when there is

    	private cycleAttempt(dir: -1 | 1): void {
    		const rowKey = this.controller?.selectedRowKey ?? null;
    		if (!rowKey) return;
    		const node = this.rows.find((r) => r.node.manifest.id === rowKey);
    		if (!node) return;
    		const browsable = browsableAttempts(node.node.manifest);
    		if (browsable.length <= 1) return; // legacy + single-attempt jobs
    		if (computeProgressLayout(this.termRowsCap, this.rows.length).progressLines <= 1) return; // header suppressed → unadvertised key must not act
    		const cursor = this.attemptCursor?.rowKey === rowKey ? this.attemptCursor.sessionId : null;
    		const shown = resolveAttempt(browsable, cursor);
    		const nextIndex = Math.min(browsable.length - 1, Math.max(0, shown.index + dir));
    		if (nextIndex === shown.index) return; // clamp: already at the endpoint
    		this.attemptCursor = { rowKey, sessionId: browsable[nextIndex]!.sessionId };
    		this.invalidate();
    		this.onRender?.();
    ```
