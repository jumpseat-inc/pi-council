# `/usages` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task (inline execution chosen by the human). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `/usages <time_range>` — a packaged procedure plus a scaffolded skill/tool that reports this repo's per-seat and main-agent token usage and dollar cost, cross-matched against OpenRouter billed activity via `OPENROUTER_MANAGEMENT_KEY`.

**Architecture:** A packaged procedure (`council/procedures/usages.md`) gates on the env var and loads a consumer-copied skill (`<repo>/.pi/skills/usages/`) whose Python tool (`scripts/usages.py`, stdlib only) harvests generation ids from pi session JSONL, council run manifests/transcripts, and the durable usage store; batch-resolves exact dollars through `POST /api/v1/analytics/query`; reconciles against `GET /api/v1/activity`; and writes JSON + Markdown under `<repo>/.pi/council/usages/`. A durable per-seat sibling is added to `extensions/usage-store.ts` so seat history survives run pruning.

**Tech Stack:** TypeScript engine (`extensions/`, bun:test), Python 3 stdlib tool, pi packages/procedures/skills, OpenRouter management API.

**Spec:** `docs/superpowers/specs/2026-09-21-usages-design.md` — read alongside this plan.

## Global Constraints

- Hard convention #3: no hardcoded `.pi` in filesystem paths — build repo-local paths from `CONFIG_DIR_NAME` (`@earendil-works/pi-coding-agent`).
- Hard convention #6: scaffold writes are non-clobbering. The new skill copy step must never overwrite an existing file.
- `TOOLING_FILES` stays exactly two (`council/cards/_template.md`, `council/validate.py`); `DATA_FILES` and the T4 set-equality guard are untouched (the skill is not in the scaffold tree).
- Durable usage record: `spend` stays byte-verbatim; new fields are additive siblings; `USAGE_RECORD_SCHEMA_VERSION` stays `2`.
- `OPENROUTER_MANAGEMENT_KEY` is mandatory; never fall back to `OPENROUTER_API_KEY`.
- No new network surface in the engine: the only network code is in the scaffolded Python tool.
- Every dollar figure carries a basis (`exact` / `catalogue-estimate` / `interpolated`); approximations are named in `limitations[]`.
- Tests use fresh `fs.mkdtempSync` roots, never the real repo; new behavior is red-first.
- Commits follow Conventional Commits; no history rewriting.

```ts
/** D1 (`/usages`) — copy the package's `council/skills/usages/` payload into
 * `<repo>/$CONFIG_DIR_NAME/skills/usages/`, non-clobbering, rendering
 * `@CONFIG_DIR@` at copy time. Deliberately outside the scaffold tree: no
 * scaffold.json provenance, no TOOLING/DATA classification, no refresh path. */
export function copyUsagesSkill(repoRoot: string, pkgRoot: string): ScaffoldResult {
	const src = path.join(pkgRoot, "council", "skills", "usages");
	const dstRoot = path.join(repoRoot, CONFIG_DIR_NAME, "skills", "usages");
	const result: ScaffoldResult = { created: [], skipped: [] };
	const walk = (rel: string): void => {
		let entries: fs.Dirent[];
		try {
			entries = fs.readdirSync(path.join(src, rel), { withFileTypes: true });
		} catch {
			return;
		}
		for (const entry of entries) {
			const childRel = rel ? path.join(rel, entry.name) : entry.name;
			const srcPath = path.join(src, childRel);
			const dst = path.join(dstRoot, childRel);
			const key = toScaffoldRel(path.join("skills", "usages", childRel));
			if (entry.isDirectory()) {
				walk(childRel);
			} else if (entry.isFile()) {
				if (fs.existsSync(dst)) {
					result.skipped.push(key);
				} else {
					fs.mkdirSync(path.dirname(dst), { recursive: true });
					const bytes = Buffer.from(renderScaffoldText(fs.readFileSync(srcPath, "utf-8")), "utf-8");
					fs.writeFileSync(dst, bytes);
					result.created.push(key);
				}
			}
		}
	};
	walk("");
	return result;
}
```

def http_json(url, key, *, data=None, timeout=30):
    req = urllib.request.Request(url, data=None if data is None else json.dumps(data).encode(),
