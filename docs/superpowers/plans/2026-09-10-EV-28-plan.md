# EV-28 Implementation Plan — full usage tuple and cost provenance in the hub usage record

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A seat dispatched through the hub accumulates, persists, and renders the full usage tuple (input, output, cacheRead, cacheWrite, reasoning, totalTokens + four flat cost components + scalar cost + turns) with `costBasis: "catalogue-estimate"` and `usageSource: "stream-assistant"` on the record, the manifest, and the `council_wait` head line.

**Architecture:** One `Usage` declaration in `extensions/runs.ts` (flat cost components beside the scalar `cost` anchor — step-6 ruling Q1). Ingestion in `extensions/hub.ts` extends the assistant-`message_end` accumulation loop with `|| 0` guards (§2.2); the single `Job.usage` initializer stamps the provenance defaults so manifest and report agree by construction (§2.3). `extensions/hub-tools.ts` extracts an exported `formatUsageSegment` (§2.5 exact literal). `extensions/eval-runner.ts` whitelists `cellScope.usage` to `{input, output, cost, turns}` at the assignment site (§2.4 / Q3). Nothing else migrates.

**Tech Stack:** TypeScript (strict), `bun:test`, `bunx tsc --noEmit`, `python3 council/validate.py`, `bash council/preflight.sh EV-28`.

**Spec:** `docs/superpowers/specs/2026-09-10-EV-28-design.md` (the contract; this plan argues from it).

// T5 — head-line bytes and the ≤160 threshold at both fixtures
test("T5: head line renders the token split with the basis, ≤160 cols at both fixtures", () => {
	const base = fullUsage({ input: 100, output: 10, cacheRead: 900, cacheWrite: 0, reasoning: 7, totalTokens: 1010, cost: 0.0013, turns: 1 });
	const seg = formatUsageSegment(base);
	expect(seg).toBe("turns=1 tokens=in 100/out 10/cR 900/cW 0/reason 7/total 1010 cost≈$0.0013 (catalogue)");
	expect((seg.match(/≈/g) ?? [])[0]).toBe("\u2248");
	const line = `[job-1] seat=owner state=done stopReason=stop elapsed=2.3m ${seg}`;
	expect([...line].length).toBeLessThanOrEqual(160);
	const wide = formatUsageSegment(fullUsage({ ...base, cacheRead: 9000 }));
	const wideLine = `[job-1] seat=owner state=done stopReason=stop elapsed=2.3m ${wide}`;
	expect([...wideLine].length).toBeLessThanOrEqual(160);
