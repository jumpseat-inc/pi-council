# EV-29 Provider-Reported Actual Cost — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** For a hub-dispatched seat whose model is served through OpenRouter, the run's durable usage record gains the provider's own reported figures (generation-level dollar total, BYOK prompt/completions split, per-component native token counts, routed upstream provider per generation), rendered as one new block row, with a record-level unavailable marker when retrieval fails.

**Architecture:** A new injected-transport module (`extensions/provider-cost.ts`) harvests each eligible job's OpenRouter generation ids from its already-persisted child session JSONL (`responseId` via `findSessionFile`/`runs.ts` — convention 12), fetches `GET /api/v1/generation?id=` under a bounded signal, and returns a `ProviderCostReport`. The flush (`extensions/usage-store.ts`) becomes async and calls the module **internally** (transport + key are the only injectables) after the choose-once file check and before persist, so the persisted `StoredUsageRecord` carries an optional `provider` sibling (`USAGE_RECORD_SCHEMA_VERSION` 1→2; `spend` byte-verbatim). The renderer gains one row after the boundary row. `extensions/hub.ts` is NOT touched.

**Tech Stack:** TypeScript (strict, `bunx tsc --noEmit`), `bun:test`, pi-coding-agent (`parseSessionEntries`, `readStoredCredential`), pi-ai (`getEnvApiKey`), global `fetch` (production transport only).

**Spec:** `docs/superpowers/specs/2026-09-11-EV-29-design.md` — the settled write-up (binding; step-6 steward + product-owner rulings quoted in `council/cards/EV-29.md`). This plan implements it; the spec wins on any divergence not observed against the tree.

## Global Constraints

- The four `Usage.cost*` slots stay `catalogue-estimate`; **no per-component `(reported)` dollar, ever** (steward A). No pro-rated figures.
- `SpendRecord` gains no field; `StoredUsageRecord.spend` stays byte-verbatim (EV-31 freeze; ruling D).
- `extensions/hub.ts` untouched (AGENTS.md convention 7). `extensions/spend.ts`, `extensions/runs.ts` untouched.
- The default test suite is fully offline: only the injected transport is exercised; the real HTTP transport is never reached (opt-in `COUNCIL_INTEGRATION=1` probe only).
- Tests root every store under a fresh `fs.mkdtempSync` dir; never write the real agent dir (T-U16 precedent).
- C3 reason literals are record-only, never rendered: `no-generation-id`, `session-missing`, `fetch-failed:<trimmed Error.message>`, `timeout`, `no-api-key`.
- R-1 literals byte-exact: `cost=$X.XXXX (reported)` via the composed `formatReportedMoney`; the catalogue `cost≈$X.XXXX (catalogue)` bytes unchanged.
- Block ≤160 columns hard; measurement rows byte-identical (C1); `formatRunnerUsageBlock` untouched (C2).
- Conventional Commits; no history rewrite on `main`; work only in `.worktrees/ev-29-provider-cost`.

Key implementation points (all from spec §2.1 "Retrieval rules" + C3 precedence):
- `collectGenerationIds`: pure; assistant `message` entries' `responseId`, file order, deduped first-occurrence-wins.
- `fetchProviderReport`: `jobs.length === 0` after filtering to `model.startsWith("openrouter/")` ⇒ `null`; `apiKey === null` ⇒ `{ status: "unavailable", reason: "no-api-key", totalCost: null, generations: [] }` (transport never called); per job read the session (`sessionPath === null` ⇒ class `session-missing`; read failure/empty ids ⇒ `no-generation-id`); per id one fetch with `AbortSignal.timeout(timeoutMs)` (default 5000); rejection with an aborted signal ⇒ `timeout`, else `fetch-failed:<trimmed message>`; success ⇒ mapped `ProviderGeneration` with `status: "reported"`, every wire field defensively read (number-or-null), `nativeTokens` present only when ≥1 native count carried (else `null`), `isByok` boolean-or-null, `fetchedAt: now()`.
- Report aggregation: `status` worst-of (any unavailable ⇒ unavailable); `reason` = first observed failure under the fixed precedence `no-api-key < session-missing < no-generation-id < timeout < fetch-failed:*` (equal class ⇒ first wins); `totalCost` = Σ over reported generations' non-null `totalCost`, `null` iff none.
- `providerComponentFigure`: `undefined` report or `status === "unavailable"` ⇒ `UNAVAILABLE_MARKER`; else Σ over reported generations of the component path's non-null value, `UNAVAILABLE_MARKER` iff none carried it (record-level accessor, R-2/E — never rendered).
- `resolveOpenRouterApiKey()`: `getEnvApiKey("openrouter")` ?? stored `readStoredCredential("openrouter")` when `type === "api_key"` and `key` is a non-empty string, else `null`.
- `openRouterGenerationTransport(apiKey)`: `fetch("https://openrouter.ai/api/v1/generation?id=" + encodeURIComponent(id), { headers: { Authorization: "Bearer " + apiKey }, signal })`; non-ok ⇒ throw `HTTP ${status}`; unwrap `body.data` (live endpoint envelope, verified 2026-09-11) with a plain-object fallback to `body`.
