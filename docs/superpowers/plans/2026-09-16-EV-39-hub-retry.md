# EV-39 — Hub-level retry of a seat dispatch with exponential backoff (Implementation Plan)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A seat dispatch whose settled report `classifyRetry` classifies `retry` is re-spawned with `computeBackoffDelay` backoff until the budget is exhausted or an attempt settles non-retryably; the final report names the attempts made (`attempts=N/M` when `N > 1`); a single-attempt dispatch's manifest and report stay byte-identical to pre-EV-39.

**Architecture:** Split ownership — `Hub` (extensions/hub.ts) owns the lifecycle state machine (new `"retrying"` state, synchronous settle hook, `respawn`, cancel/wait clauses, pid-file discipline); a new `extensions/job-retry.ts` owns classification + attempt counter + unref'd injected backoff timer; `extensions/hub-tools.ts` (council_dispatch) owns the spawn inputs and wires the supervisor with a shared `once()`-guarded cleanup; `extensions/index.ts` injects the one init-time `RetryPolicy` snapshot. Both pure functions (`classifyRetry`, `computeBackoffDelay`) are reused verbatim — no second copy.

**Tech Stack:** TypeScript (strict, `bunx tsc --noEmit`), `bun:test`, node:child_process stub child.

**Spec:** `docs/superpowers/specs/2026-09-16-EV-39-design.md` (authoritative; where this plan and the spec disagree, the spec wins). Card: `council/cards/EV-39.md` (R4 + Q4 binding).

## Global Constraints

- Manifest cardinality **(A)**: one job id, one `<id>.json`, one tree row, **cumulative** `usage` carried across attempts (spec §1.3, §2.2).
- **D1:** `startedAt` is set once at first spawn and never re-based; the per-attempt clock is `attemptStartedAt` (spec §1.4, §2.2).
- **D2:** during backoff set `exitCode = null` AND `pid = undefined` together (spec §1.5, §2.2).
- **O-4:** fresh session id per attempt `<id>-attemptN` for N ≥ 2 (provisional; EV-42 finalizes); attempt 1 keeps `sessionId = jobId` (byte-identical manifest).
- **AGENTS.md §7:** every `hub.ts` behavior delta lands only with a failing test first.
- **G1:** a non-retry dispatch's manifest and `N=1`/absent-`attempts` `formatReport` output are byte-identical to pre-EV-39; EV-28's byte tests stay green.
- **Q1/D3/O-8:** exactly ONE `loadRetryConfig(repoRoot)` call site (in `extensions/index.ts`, moved before `registerHubTools`/`registerNavigator`); the snapshot getter is injected into hub tools + navigator; no render path reads config.
- **Q4 disclosure (steward):** `ProviderCostReport.partial?: "final-attempt-only"`, set in `usage-store.ts` when an eligible `openrouter/` manifest has `(m.attempt ?? 1) > 1`; `usage-block.ts` renders `usage  partial = reported figure is final-attempt-only` iff `provider.partial` is present. Machine-readable + durable, never prose-only.
- **Q3:** no new refresh ticker in the navigator — the existing 2 s refresh is the countdown.
- **No new glyph, no new theme token.** The tree/navigator reuse existing glyph slots: `retrying → "⏸"` (`STATE_ORDER = 0`, `STATE_TOKEN = "warning"`).
- Out of scope (steward Escalation 1): EV-42's per-attempt provenance, EV-41's fixture, `attemptGroupId`, the parent-turn loop (EV-40).
- Commits: Conventional Commits (`feat(hub): …`, `test: …`); commit after every green slice.
- Gate order for every run: `bash council/preflight.sh EV-39` → `bunx tsc --noEmit` → `bun test` → `python3 council/validate.py`.

```ts
// EV-39 — the hub-level retry supervisor (spec §2.3). Pure-decision module:
// classification + attempt counter + unref'd injected backoff timer. It owns
// NO spawn inputs (council_dispatch holds those, spec §2.1) and NO lifecycle
// state beyond its own handle (Hub owns the job's). Both pure functions are
// reused verbatim from retry.ts — the EV-40 §2.8 watch item forbids a second
// copy of either the classifier or the delay function.
import type { Hub, Job, JobReport } from "./hub.ts";
import { classifyRetry, computeBackoffDelay } from "./retry.ts";
import type { RetryPolicy } from "./seats.ts";

export interface RetrySupervisorHandle {
	/** Hub settle hook. Returns true when the dispatch stays alive (retrying);
	 * the Hub then writes the retrying manifest, keeps the pid file clean and
	 * withholds the cleanup (this handle owns it). */
	onSettle(job: Job, report: JobReport): boolean;
	/** Clears the pending timer and runs the held cleanup exactly once. Idempotent. */
	dispose(): void;
}

export interface RetryAttemptSpec {
	args: string[];
	env: Record<string, string>;
	cwd: string;
	sessionId: string; // MUST be `${jobId}-attempt${n}` (O-4, provisional)
	timeoutMs: number;
	stallMs: number;
}

export interface RetrySupervisorInput {
	hub: Hub;
	jobId: string;
	policy: RetryPolicy;
	/** Once-guarded real cleanup, shared with the Hub's non-retry settle path. */
	cleanup: () => void;
	/** Builds attempt n's spawn spec (n ≥ 2). Pure. */
	attemptSpec: (n: number) => RetryAttemptSpec;
	setTimer?: (fn: () => void, ms: number) => { cancel(): void; unref?: () => void };
	rand?: () => number;
}

export function createRetrySupervisor(input: RetrySupervisorInput): RetrySupervisorHandle {
	const setTimer = input.setTimer ?? defaultSetTimer;
	const rand = input.rand ?? Math.random;
	let disposed = false;
	let timer: ReturnType<typeof setTimeout> | { cancel(): void } | undefined;

	function clearTimer(): void {
		const t = timer as { cancel?: () => void } | undefined;
		if (t && typeof t.cancel === "function") t.cancel();
		else if (t) clearTimeout(t as ReturnType<typeof setTimeout>);
		timer = undefined;
	}

	function fire(): void {
		timer = undefined;
		if (disposed) return;
		const job = input.hub.get(input.jobId);
		if (!job || job.state !== "retrying") return; // cancelled or disposed path
		input.hub.respawn(input.jobId, input.attemptSpec(job.attempt ?? 2));
	}

	function defaultSetTimer(fn: () => void, ms: number): { cancel(): void; unref?: () => void } {
		const t: ReturnType<typeof setTimeout> = setTimeout(fn, ms);
		t.unref?.();
		return { cancel: () => clearTimeout(t) };
	}

	return {
		onSettle(job, report) {
			const verdict = classifyRetry(report);
			const current = job.attempt ?? 1;
			if (disposed || !input.policy.enabled || verdict !== "retry" || current >= input.policy.maxAttempts) {
				return false; // final settle — the Hub runs the cleanup
			}
			const next = current + 1;
			const delay = computeBackoffDelay(input.policy, next, rand);
			job.attempt = next;
			job.state = "retrying";
			job.exitCode = null;       // D2 — settledness retracted…
			job.pid = undefined;       // D2 — …and the dead pid retracted together
			job.settledAt = undefined;
			job.nextAttemptAt = Date.now() + delay;
			clearTimer();
			timer = setTimer(fire, delay);
			return true;
		},
		dispose() {
			if (disposed) return;
			disposed = true;
			clearTimer();
			try { input.cleanup(); } catch { /* best effort, exactly once */ }
		},
	};
}
```
