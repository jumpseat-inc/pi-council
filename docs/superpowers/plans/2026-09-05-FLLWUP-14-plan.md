Binary: `<prefix>/node_modules/.bin/pi` → `@earendil-works/pi-coding-agent/dist/bundle/cli.js`. `pi-tui` is NESTED at `<prefix>/node_modules/@earendil-works/pi-coding-agent/node_modules/@earendil-works/pi-tui` — `NODE_PATH` must point at the nested node_modules for the R-2 `node -e` (`require("@earendil-works/pi-tui")`).
2. R-2 assertions verified: `\x1b[47u`→`/`, `\x1b[99u`→`c`, `\x1b[108u`→`l`, `\x1b[97u`→`a`, `\x1b[122u`→`z`, `\x1b[233u`→`é`; `matchesKey("\x1b[127u","backspace")`, `("\x1b[27u","escape")`, `("\r","enter")`, `("\x1b[B","down")`, `("\x1b[A","up")` all true; `isKeyRelease("\x1b[47u")` false; suffixed `\x1b[47;1:1u` decodes to `/`; `matchesKey("\x1b[47;1:3u","anything")` false (release filtered).
3. Catalogue (bundled `openrouter.json` + `flattenModelCatalog`): `"cla"` → 32 hits, `"zz"` → 0, `é` → 0; `deepseek/deepseek-v4-flash-0731` present. Model-level cross-product rows ≈ 1400 (351 ids × level sets).
4. Extension registration on the host: `pi install -l "$REPO_ROOT"` from the fixture-copy work dir writes `.pi/settings.json` with a relative packages path; with `defaultProjectTrust: "always"` in the scratch `$HOME/.pi/agent/settings.json` + `--approve`, the extension loads and `/council-models` headless prints the R-2 usage line + per-seat listing, `exit 0`, ZERO network, with `OPENROUTER_API_KEY=sk-dummy`. Without the env-var cleanup in 5, it does not.
5. COUNCIL_SEAT set → extension factory enters child mode (`runChildMode`) and registers no parent commands — the headless probe and TUI must run with COUNCIL_SEAT/COUNCIL_JOB_ID/COUNCIL_RUN_ID unset (and PI_SESSION_FILE is harmless to unset).
6. TUI in pty (80×28, TERM=xterm-256color): boot emits the kitty query `\x1b[>7u...`; answering `\x1b[?1;2c` (DA) + `\x1b[>1u` (kitty flag 1) is sufficient; pi never blocks on unanswered queries. `/council-models\r` opens the full-screen modal overlay.
7. Modal rendering (verified live): `withModalFrame` draws a bordered panel (border top at some panelTop; header line = `│ council models — pick a model per seat … │`; body rows; footer; bottom border) at panelLeft=2, contentWidth 72, `panelTop = floor((rows-panelHeight)/2)`. Repaint protocol: per row — cursor-up/position CSI + `\r` + `\x1b[2K` + SGR-styled text + `\r\r\n`. Rows are truncated at content width with the BUG-1/EV-27 truncation semantics visible only for long ids; the ruled literals fit.
8. Live frame literals (dechromed lines, verified byte-exact): header `council models — pick a model per seat`; search row `▌ / filter · esc clears` (U+258C at content column 0, then the hint); `▌ é` after `\x1b[233u` with `No models matching "é".` + `↓ then esc exits search` (é never matches the catalogue → no-match copy); `▌ zz` + `No models matching "zz".` + `↓ then esc exits search`, footer last, never a fifth footer; after Esc-Esc the line goes back to `▌ / filter · esc clears` (clear-and-stay); after Down then Esc → provider-level frame `> OpenRouter` + `↑/↓ move · enter open · esc back` last, no `▌` anywhere; frame 2 (model level pre-press) shows PRE_SEARCH_HINT penultimate and FOOTER_MODEL last, `No providers configured …` absent, ≥1 provider row.
9. Deep-match finding (governs the structural rule): the frame-2 pre-press window shows only the first ~23 catalogue rows; a filtered set like `"cla"` includes rows far deeper in the id order (e.g. `openrouter/anthropic/claude-haiku-4.5`). The spec's "every visible row ⊆ pre-press rows" is only true when the pre-press capture covers the WHOLE catalogue. Resolution (spec §4.3 + §4.4 "the assertion follows the live render"): the pre-press capture WALKS the model list (Down presses, batch 10, 0.15s settle, drain continuously; stop after 3 no-op batches at the bottom), yielding the full row universe; after the walk, Esc (ascend) + Enter (re-enter model level) resets the cursor to index 0 and re-arms the hint (unobservable — the hint only matters pre-frame-3). Derivation: `derived = [r for r in universe if q.lower() in id_minus_level(r).lower()]`; the search-mode visible window is `maxRows-1` (FLLWUP-15 shrink — 22 vs 23 in the 28-row pty; the driver takes the search-window size from the frame-3 empty-query snapshot, never hardcodes it); assert the live visible id list == `derived[:window]` and every visible row contains q; assert every visible row ∈ universe (walk-coverage guard — a red means the walk missed rows: calibrated failure, not a false pass).
10. Header location for "line 1" (spec §4.3: "line 1 = the body row directly below the modal header"): with the frame border, the header sits at screen index 1 (index 0 = `┌──` border top). The driver locates the header line by literal match and defines "line 1" as the dechromed content line immediately below it — position-independent, matching the spec's intent and fixed-index host of the border.

## Task 4: `smoke/search-smoke/driver.py`

**Files:**
- Create: `smoke/search-smoke/driver.py`

Structure (python3 stdlib ONLY — greppable claim: no import of any pi/extension module):

- Module constants: the ruled literals (HEADER, SEARCH_ROW_EMPTY, SEARCH_HINT, PRE_SEARCH_HINT, NO_MATCH_OPEN/…, NO_MATCH_HINT, FOOTER pretty, FOOTER_MODEL, EMPTY_NO_PROVIDERS) copied byte-exact from `extensions/model-picker.ts` (source-verified in bring-up); USAGE_LINE from `extensions/council-models.ts` (used only for messages/diffs, not probed — the probe runs in run.sh).
- `Screen` class (the ~150-line screen model): 28×80 cell grid; `feed(data)`: ANSI cursor handling (CUP/CHA `Hf`, `A/B/C/D`, erase `K`, SGR `m` ignored), UTF-8-aware char writes (1–4 bytes), CR/LF semantics, OSC hyperlink skipping (`\x1b]8;;…\x07` / `\x1b]8;;…\x1b\\`), NUL skip; `snapshot()`: per-row strings, rstripped → `lines`; `dechrome(line)`: strip a leading `│ ` and trailing ` │` → content; `content_lines()` = dechromed non-border non-empty lines (border = line whose stripped text is only `┌─┐└┘│ `).
- `Session` class: pty master/slave, winsize 80×28 via `fcntl.ioctl(TIOCSWINSZ)`; env = os.environ minus COUNCIL_* plus TERM/HOME/OPENROUTER_API_KEY; spawn via fork/execve; `send(bytes)`; `drain(seconds)`; `wait_stable(require=3, quiet=0.08, ceiling)` → drains into a growing byte log, returns when `require` consecutive quiet polls pass or ceiling hit; per-checkpoint: `mark()` starts a fresh byte capture; `frame()` = Screen fed the bytes since mark.
- Keystroke map (bare CSI-u): `SLASH=b"\x1b[47u"`, `C=b"\x1b[99u"`, `L=b"\x1b[108u"`, `A=b"\x1b[97u"`, `Z=b"\x1b[122u"`, `EACUTE=b"\x1b[233u"`, `BS=b"\x1b[127u"`, `ESC=b"\x1b[27u"`, `CR=b"\r"`, `DOWN=b"\x1b[B"`, `UP=b"\x1b[A"`.
- Assertion helpers: `assert_contains`, `assert_exact_line(frame, content_lines, idx, literal)`, `footer_is(content_lines, literal)` (footer = last content line), `no_258c(frame)` (no U+258C in any stripped line), `header_index(frame)` (line whose content startswith HEADER).
- Frame steps (all waits timeout-ceiled; every wait drains into the session log; marks delimit checkpoints):

  1. Spawn pi; drain boot; **assert** boot bytes contain `\x1b[>7u` (pi asked for kitty mode — objection-7 scope); reply `\x1b[?1;2c` + `\x1b[>1u`; wait stable (prompt settle).
  2. Send `/council-models\r`; wait stable; mark; **F1** (seat level): header present; ≥1 seat row; footer == FOOTER_SEAT_PROVIDER last; no `▌`.
  3. Send `\r\r`; wait stable; mark; **F2** (model level): rows; PRE_SEARCH_HINT penultimate; FOOTER_MODEL last; `▌` absent; EMPTY_NO_PROVIDERS absent.
  4. Pre-press universe walk: repeated `DOWN` batches (10 per batch, 0.15s settle each, drain continuously), capturing every dechromed model row into `universe` (dedup by id-minus-level); stop after 3 consecutive batches where the selected row's id did not change (bottom). Then `ESC` (ascend), `\r` (re-enter model level, index 0). Sanity: visible slot-0 row after re-entry == first id (soft check, not asserted).
  5. Send `\x1b[47u`; wait stable; mark; **F3** (search opens): line under header == SEARCH_ROW_EMPTY byte-exact; PRE_SEARCH_HINT absent from frame; FOOTER_MODEL last; **capture search-window size** W = number of visible model rows in this frame (FLLWUP-15 shrink window).
  6. Send `\x1b[233u`; wait stable; mark; **F4 (é falsifier)**: line under header == `▌ é`; derived=[] → exactly NO_MATCH("é") + NO_MATCH_HINT present and FOOTER_MODEL last (follows the live render). Send `\x1b[127u`; wait stable; mark; assert line under header == SEARCH_ROW_EMPTY (backspace deleted é → empty).
  7. Send `\x1b[99u\x1b[108u\x1b[97u`; wait stable; mark; **F5 (cla)**: line under header == `▌ cla`; derive `derived=[r for r in universe if "cla" in id_minus_level(r).lower()]` (non-empty); assert live visible ids == `derived[:W]` (ordered), every visible row ∈ universe, every visible id contains "cla"; FOOTER_MODEL last.
  8. Send `\x1b[127u`; wait stable; mark; **F6 (cl)**: line under header == `▌ cl`; same structural rule for "cl" (derived ⊆ universe by construction; assert equal + subset + contains); FOOTER_MODEL last.
  9. Send `\x1b[27u` (clear — spec flow requires the no-match query alone); wait stable; mark; assert line under header == SEARCH_ROW_EMPTY. Send `\x1b[122u\x1b[122u`; wait stable; mark; **F7 (zz)**: line under header == `▌ zz`; derived([])==[] → exactly `No models matching "zz".` then `↓ then esc exits search`; FOOTER_MODEL last; assert NO_FIFTH_FOOTER (no footer literal anywhere but the last line).
  10. Send `\x1b[27u\x1b[27u`; wait stable; mark; **F8 (Esc-Esc)**: line under header == SEARCH_ROW_EMPTY; header unchanged; FOOTER_MODEL last (clear-and-stay; second Esc cannot ascend).
  11. Send `\x1b[B`; short settle; send `\x1b[27u`; wait stable; mark; **F9 (Down, Esc)**: header; provider rows (≥1, structural); FOOTER_SEAT_PROVIDER last; no `▌` anywhere.
  12. Verdict: all frames green → print per-frame PASS + total; write artifacts to `<out>/` (raw streams per frame, stripped frames, universe rows, diffs); exit 0. Any red → print per-line diffs (expected vs actual content lines), write artifacts, exit 1. No retries.

- `id_minus_level(row)`: strip the leading `> ` / `  ` marker and the final `:level` segment iff it matches `^(off|minimal|low|medium|high|xhigh|max)$` — mirrors `filterModelRows` (match on qualifiedId, case-insensitive substring; the suffix is applied at render time; `:batch`-style id segments are preserved because only the LAST segment is stripped).
