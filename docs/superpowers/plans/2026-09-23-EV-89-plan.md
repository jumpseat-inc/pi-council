## Global Constraints (verbatim from the spec)

- Mechanism only. **No `council/phase1-rulings.json` is written anywhere** —
  not in the branch, commits, or PR (J1). If any step appears to need it, stop.
- Canonical class strings (pinned verbatim, §2): `surface copy`,
  `state and field naming`, `uncertainty display`, `error and empty-state
  text`, `gate user-visibility`. Tier literals, in order: `card`,
  `run-committing`, `portfolio`.
- `validate.py` carries **zero** canonical class-name strings; tier literals
  only. No completeness, no membership, no anti-shrug predicate. Named
  `FAIL:` lines, never a traceback.
- Authorization sentence (§5) enters the procedure **verbatim**, bold
  markers included.
- Refusal stem: `Phase 1 unresolved: <class>` — one line per unresolved
  class, all of them, explicitly not the generic `HALT:` line.
- Conventional Commits; `version` bump in `package.json` in the same PR.
- Never touch: `council/board.md`, `council/cards/EV-89.md`, `vault/**`,
  `extensions/**`, gate data, `council/scaffold/` record seeding.
- No `fixtureVersion` bump — only the 8 `seed.treeDigest` re-pins.
- All 10 `validate.py` copies byte-identical (root + scaffold + 8 seeds).

## Review Focus (spec-implied, not task-tested)

1. A `reason` whose value is a non-string (e.g. `42`) must FAIL, not crash —
   covered by falsifier arm "reason without prefix" (isinstance guard first).
2. A top-level JSON array (`[1,2]`) or scalar record must FAIL via the same
   "no `classes` array" diagnostic, not a traceback — falsifier arm 2.
3. A record with `stakes` values in tier order but duplicated class names
   still FAILs (order check must not mask the duplicate) — duplicate arm
   asserts the duplicate diagnostic fires on an otherwise well-ordered record.
4. Absent-file-skip must hold for a scaffolded consumer repo — the falsifier
   copies the packaged `validate.py` into a bare temp council tree (no
   `council/gate/` at all), so arm 1 exercises the consumer shape directly.
5. The fences' FAIL lines must name the entry (`classes[i]`) so an operator
   can locate the defect from the line alone — asserted per red arm.
