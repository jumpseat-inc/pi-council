# EV-32 — usage reported at every autonomous exit point — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A deterministic, byte-stable usage block (token split + provenance-labelled money + accounting boundary) emitted at all five autonomous exit points — `/features-new`, `/features-deliver`, `/council` (via the flush's `written` transition), `/council-eval` (marker mode + awaited-tail drain), and a council-runner's card execution (`council_wait` report) — with the three ruled whole-block states (failed > unresolved > empty) and tests asserting the numbers equal the fixture accounting record.

**Architecture:** One pure renderer (`extensions/usage-block.ts`) composing the extracted token/money fragments (`extensions/usage-format.ts`) and `formatBoundaryLabel` (`spend.ts`); the marker-vs-user-message boundary discriminator rides the EV-31 pending ledger as `boundaryMode` and is realized inside `spendRecord` as an opt-in anchor; five render sites are wired in `usage-store.ts` (flush notify), `index.ts` (scanned handler + `/council-eval` via a `deps`-injected factory), and `hub-tools.ts` (`council_wait` report).

**Tech Stack:** TypeScript (strict), bun:test, pi extension API. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-09-11-EV-32-design.md` (authoritative), as amended by the step-6 `steward` ruling (A/B/I) and `product-owner` ruling (C–J) recorded on `council/cards/EV-32.md`. Where spec and ruling disagree, the ruling wins. Nothing settled is reopened here.

## Global Constraints

- All lines of every rendered block carry the `usage  ` (two-space) prefix; every line ≤160 columns; U+2248 for catalogue money, U+2014 in the failure literal; no ANSI, no locale, no clock, no I/O in the pure modules.
- Three whole-block states, precedence **failed > unresolved > empty**:
  1. `usage  no usage recorded` — `boundary.resolved === true` and every numeric metric of both halves is 0.
  2. `usage  accounting failed — <reason>` — the `{ failed }` variant.
  3. `usage  accounting boundary unresolved` — `boundary.resolved === false`.
- Measurement row grammar (PO F): `usage  ` + half label (`ownSession`|`subtree`) `.padEnd(10)` + two spaces + `basis=<record.<half>.usageSource>` (read from data) + two spaces + `formatTokensFragment(u)` + one space + money (`formatMoney(u)`, or the literal `cost=n/a` when that half is named in `unavailableCost`).
- Boundary row (points 1–4): `usage  ` + `formatBoundaryLabel(record)` verbatim. Runner boundary row (point 5): composed directly as `usage  boundary=session=<jobId> entries=unresolved jobs=<n>` — `formatBoundaryLabel` is NOT called (it hardcodes `jobs=0`).
- Legend row (PO D/E): `usage  n/a = provider figure unavailable`, present iff `unavailableCost` names ≥1 half; absent in the runner form and in every whole-block state. No slot renders `n/a` from real data until EV-29.
- Runner block (PO C): no `ownSession` line; one `subtree` line whose numbers equal `sumSubtreeUsage(manifests, report.id)` over every numeric metric; runner zero state remains state 1.
- `spendRecord` gains `boundaryMode?: "user-message" | "marker"`, default `"user-message"` preserving today's behavior byte-for-byte; `SpendRecord`/`SpendBoundary` shapes untouched; EV-30's zero-both invariant stands (marker absent/off-chain in marker mode → identical unresolved zero-both).
- Never `sendUserMessage` for the block; sink is `ctx.ui.notify` (TUI) / `console.log` (headless), dual-routed.
- Every bash call carries an explicit timeout; no foreground servers; the network integration test stays behind `COUNCIL_INTEGRATION=1`.
- Main-repo immutability: all work happens in the worktree `.worktrees/ev-32-usage-block` on branch `ev-32-usage-block`; never `git checkout`/`switch`/`reset` the main checkout.
- Conventional Commits on every commit.
- Gates, in order, from the worktree at head: `bash council/preflight.sh`; `bunx tsc --noEmit`; `bun test`; `python3 council/validate.py`.
