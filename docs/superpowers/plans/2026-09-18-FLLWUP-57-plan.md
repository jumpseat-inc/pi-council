**Goal:** `bun test` is shell-independent for every catalogue-valid `COUNCIL_EVAL_MODEL` value: no test in `test/` resolves an uncontrolled ambient as its effective model.

**Architecture:** The ambient is read in exactly two engine places — `extensions/dispatch.ts:55` (`spawnSeatJob`) and `extensions/hub-tools.ts:174` (`council_dispatch` execute) — and resolved by `resolveEffectiveModel` (`extensions/seats.ts:415`, param > env > config > frontmatter). A catalogue-valid ambient therefore *resolves as the effective model* (a different path from the loud-refusal path FLLWUP-40 probed). The fix extends FLLWUP-40's pin/clear-with-restore invariant to the one file still relying on masking: `test/override.test.ts` clears the ambient in a file-scoped `beforeEach` and restores the shell value in `afterEach` (runs on every path, including failure), so each dispatch-driving test starts controlled instead of inheriting ordering luck.
