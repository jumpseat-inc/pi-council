## Intent

One shared consent/backup/idempotency contract for the five write surfaces, so it is not re-implemented per surface. Consent is per-surface behind one consolidated plan echo (echo-then-run): each line echoed is one write. "Matches" is defined semantically per surface — `vault/wiki/**` is not byte-stable across runs (it is regenerated by the ingest skill) and `.pi/council/mcp.json` is server selection, not a whole-file write, so a byte-equality predicate would be wrong for both. `preflight.sh` stays a write surface with no AGENTS.md convention-6 amendment: the append goes only inside the scaffold's own marker-guarded "adapt to your project" section, and the data-class enumeration governs `/council-update`'s refresh direction, not this one. The consent receipt folds into the existing `scaffold.json` provenance record rather than inventing a second audit trail.

## Acceptance

Refused consent → zero files for that surface; consented overwrite → backup holds pre-write bytes and target holds new bytes, for all five surfaces; second run over identical values → bytes and mtime unchanged; the write is recorded in `scaffold.json`.
