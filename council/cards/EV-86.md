## Intent

The pure heart of the seat-composition decision: `decideSetup()` maps a packed composite to exactly one of `Default` or `Redefine` with a basis string, offline and with no network. The fail-safe direction is `Default` — the packaged scaffold — so an unanswered question, a sub-floor answer, or an unreachable disposition can never invent a custom roster. A fixture band whose policy carries a `Redefine`-producing threshold asserts that `Redefine` is actually reachable; `Default` is not only the failure path.

## Acceptance

Each composite band yields its named disposition, and at least one offline fixture band whose policy carries a Redefine-producing threshold asserts the literal `Redefine`, while a confident answer below that threshold asserts the literal `Default` (so `Default` is not only the failure path and a `decideSetup` that unconditionally returns `Default` fails this assertion); unanswered → `Default`; sub-floor → `Default`; the function is pure (no I/O, no network) and provable offline; the fail-safe arm is asserted with the exact literal.
