## Intent

The single code gate that makes "must not merely warn" real. The validator is the precondition for the writer call — it does not write, and `writeSeatOverride` (shared with `/council-models`) is unchanged, preserving gate parity: the persistence layer stays no stricter than the loader. The floor is a capability predicate over an ordered named tier set, not a rank, so "principal and steward sit in the deepest tier" is a relational constraint rather than a vacuous label. Both default profiles must be legal independently: the packaged frontmatter defaults and the scaffold seed differ on 7 of 9 seats today, and nothing requires them to agree.

## Acceptance

Each of the six violation literals is returned exactly for its class; both default profiles validate ok; a below-tier model on principal, steward, or owner returns `tier-floor`; a judge model equal to any generator's returns `judge-model-collision`; skeptic equal to owner returns `skeptic-model-collision`.
