## Intent

User-visible surface: the presentation a person reads to answer "which
model should I pin for this seat or command." Two rankings — one per
command, one per seat — each row showing model, repeat count, score mean,
and variance, ordered by score. Confidence is labeled honestly from the
records (e.g. "n=3, σ=0.20") rather than as a single unqualified number.
Empty state shows when no runs exist yet ("No eval runs yet — run `/eval
…`") and is truthful rather than a zero-filled table. Copy for the state
names, column headers, and the empty-state line is deliberated here.

## Acceptance

- The view renders per-command and per-seat rankings with repeat count,
  mean, and variance per row, ordered by score.
- With no results records, the view shows the empty state, not a zero table.
- `python3 council/validate.py` passes after any board or card changes.
