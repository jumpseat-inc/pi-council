## Intent

The operator enables/disables jev-for-decisions with one command and sees what
changed; the slash command's echo is the copy surface (TUI and headless), and it
must share the loader so the printed value cannot drift from what dispatch
resolves. Operator-facing copy says "gate"; "jev" appears in no operator-facing
string.

## Acceptance

- on→off→on round-trip; echo == loader resolution (echo-then-run).
- Every other top-level key byte-preserved, including unknown future keys.
- No-arg form prints the resolved mode.
- Unknown arg fails loud; a redundant set leaves the file byte-identical.
- Atomic EV-24 writer discipline.
