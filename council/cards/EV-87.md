## Intent

One call per setup run over the shared, domain-neutral transport: pinned model `GATE_PINNED_MODEL`, pinned `GATE_ENDPOINT`, exactly one POST, never a chat/completions path. On any refusal, timeout, non-2xx, unparseable body, or unresolved credential it records `gate call failed: <reason>`, resolves `Default`, and produces zero `Redefine` dispositions; with `gate.mode` off it records the distinct basis `off` and issues no call. The rendered `Mode: <disposition> — <basis>` line is presented, never written to a card file, and its `resolvedMode` is never consumed as a card route by `resolveRoute`.

## Acceptance

Exactly one POST per call, pinned model and endpoint, never the forbidden chat path; every failure class yields status failed, disposition `Default`, basis exactly `gate call failed: <reason>`, and one ledger line; no pathology produces an automatic `Redefine`; the transport is imported, not re-declared; a success-path fixture whose transport returns a Redefine-producing answer set asserts `resolvedMode` is the literal `Redefine`, and a `Default`-producing pack asserts the literal `Default` — the assertion names the specific literal, so a `Default`-only implementation fails; `gate.mode` off yields the distinct basis literal `off` (never `gate call failed: <reason>`); the setup line's `resolvedMode` is never consumed as a card route by `resolveRoute`; the `Mode: <disposition> — <basis>` render is presented, never written to any card file.
