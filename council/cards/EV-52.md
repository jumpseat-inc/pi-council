## Intent

This is the interview surface. The screen is the parent-TUI modal driven by the rpiv-ask-user-question extension; the state surface is /council-init's post-scaffold notify line naming the next step. The copy set the owner must write into the procedure: the per-question header carrying the cited profile field, the recommended option listed first with the literal `(Recommended)` suffix on its label (the tool ships this grammar — no council-private marker token), the trade-off in the option description, the validator-refusal-and-re-ask copy naming the violation literal, the "not detected — cannot recommend" state for an empty profile field, and the explicit consent act. The states are: empty (no question yet), loading (probe phase), question-open, refusal-re-ask, empty-profile-field, idempotent-resume, and host-cannot-ask (print the profile plus every question and resume interactively, the remote-oauth-login idiom).

The seat-composition question is the one recommendation that does not cite a deterministic profile field: its recommendation is the Jev setup disposition, and it renders the disposition's basis so `gate.mode` off (the literal `off`) is distinguishable from a failed Jev call (`gate call failed: <reason>`). A `Redefine` disposition asks the per-seat persona question for every retained seat and, after consent, writes only `seat-emphasis/<seat>.md` — never a new agent file and never a packaged-body fork. The interview must not ask the per-card-class seating question until EV-55 has a mechanism.

## Acceptance

Seat-composition decision obtained once before the first question; human asked regardless of disposition; `gate.mode` off or any setup-call failure yields the `Default` recommendation and zero custom-seat/emphasis writes before consent; non-empty question set each citing a profile field — the seat-composition question being the one exception: it cites the Jev setup disposition and its basis; below-tier proposal refused with the literal name and re-asked; a redefined roster that omits a frozen-roster seat refused by the validator with the literal `frozen-seat-missing` and the redefinition question re-asked; the rendered recommendation displays the disposition's basis and distinguishes `gate.mode` off (literal `off`) from a failed Jev call (`gate call failed: <reason>`); a `Redefine` disposition asks the per-seat persona question for every retained seat and writes only `seat-emphasis/<seat>.md` after consent (plus, once EV-55 lands, its seating question) — never a new agent file, never a packaged-body fork; zero writes before consent; empty profile field yields the not-detected state; host-cannot-ask degrades to print-and-resume with zero writes.
