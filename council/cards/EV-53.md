## Intent

/council-init's post-scaffold notify output and the transition into the interview turn. The engine layer owns the gate because only it can observe the host: a bare send produces a model turn with no invocation boundary, so the handler must stamp the boundary before sending, and the handoff must not fire when the host cannot ask. States: fresh-repo (scaffold + handoff), re-run (scaffold no-op + handoff), headless/host-cannot-ask (report "initialized, not configured", write nothing — decline is a first-class no-write state). The gate signal is `ctx.hasUI`, not `ctx.mode != 'tui'`: RPC hosts can genuinely ask, and a markdown procedure has no `ctx` and no exit code to set.

## Acceptance

Invocation boundary stamped before the send; `ctx.hasUI` true → setup turn sent; `ctx.hasUI` false → "initialized, not configured" reported with zero writes; fresh-repo, re-run, and headless states each covered.
