## Intent

This is the epic's end-to-end falsifier and release gate: it proves the ruled
surface on a live `pi` against a fixture clone pinned to a known commit, not
only against a fake `ctx`. The TUI arm (pty) shows the byte-exact identity once
at start-up and never again (no re-fire on `/reload` or resume). The rpc arm
emits exactly one `extension_ui_request` notify frame on stdout. The headless
arms (`-p`, `--mode json`) put nothing on fd 1. It runs credential-free, gated
behind the existing opt-in integration flag, on the shared pty kit, and carries
a seven-field red-at-base record per arm against the commit preceding EV-58's
merge.

## Acceptance

- TUI arm (pty): start-up shows the clone's byte-exact identity once; a
  `/reload` and a resumed session in the same run show no second identity line.
- RPC arm (piped stdout): exactly one `extension_ui_request` frame with
  `method: "notify"` and byte-exact identity message.
- Headless arms (`-p`, `--mode json`): no line matching `council: pi-council
  v` anywhere on fd 1.
- All arms run credential-free (identity emits at `session_start`, before any
  dispatch) and are gated behind the existing opt-in integration flag.
- The tests ride the shared pty kit, not a private harness.
- Each arm carries a seven-field red-at-base evidence record against the commit
  immediately preceding EV-58's merge.
