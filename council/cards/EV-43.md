## Intent

This card is the reachability gate EV-40 sits on. The extension listens to
`agent_settled` (`extensions/index.ts:379`), not `agent_end`. If both branches
return no, EV-40's intent becomes a different card — the intake's surface
becomes a "cannot recover, restart" copy string that must be carved as a new
card by the epic's owner.

## Acceptance

The falsifier runs on the shipped tree and reports, per branch, whether a
second assistant message arrives when an `agent_settled` handler invokes
`sendUserMessage`. The headless observable is the stdout line announcing the
wait (the `-p` print output of the second assistant message). The TUI
observable is the conversation-tail delta above the input bar: the input bar
is empty in both arms, so the distinguishing evidence between treatment and
control is the continuation row in the rendered conversation tail, not a
write into the input bar.
