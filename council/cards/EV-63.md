## Intent

Code owns control flow. The decision function is a pure function of answers and
policy — a weighted composite, confidence floors, and hard deterministic
overrides — never a model-chosen next action and never a loop. Skipping
deliberation is the dangerous error and deliberating unnecessarily is only
expensive, so the asymmetry is structural: one-way doors, public contracts and
data migrations, and cross-module blast radius bypass the model entirely and
return `Deliberate` regardless of what the answers say; an answer below its
floor escalates rather than guessing; and a reduced mode requires positive
evidence, not the absence of a warning.

The function returns two things, not one. The mode says how the card runs; the
seat-inclusion set says which roles run, because metering panel composition and
metering the mode are the same decision and splitting them would create two
sources of truth for the roster. A reduced set must still contain an adversary
and a ruling authority, and the two invariant roles are never removed by the
gate.

The transport's answer shapes are fixed and differ by question type, which the
decision function must respect rather than smooth over: a `choice` answer
carries the chosen label, a `probabilities` map keyed by option, and a
`confidence`; a `score` answer carries a `score`, a `legend` mapping each index
to its criterion, `probabilities` keyed by index, and a `confidence`; a `noul`
answer carries only its probability — there is no `confidence` field to floor.
The floor therefore guards the two types that report one, and a `noul` answer is
compared against the policy's own `noul` threshold instead of being silently
treated as confident.

This is the card that makes the whole feature provable offline: fixtures drive
every override and floor with no network, so the composite weights can be tuned
by a coefficient change without touching a prompt.

## Acceptance

Every override class returns `Deliberate` against an all-mechanical answer set;
a below-floor `choice` or `score` answer returns `Deliberate`; a reversible,
low-blast-radius, decidably-testable answer set returns the reduced mode with an
inclusion set that still contains an adversary and a ruling authority; the
distinct non-invariant roles are each absent from at least one reduced-set
fixture; and the whole suite runs with no network access. `decide(answers,
policy)` also returns a one-line `basis` string derived deterministically from
the answers and the override that fired (e.g. `reversible? no (public schema)`),
and a fixture proves the same answers produce the same basis bytes with no model
call in the path. The confidence floor applies to `choice` and `score` answers;
a `noul` answer carries no `confidence` field and is compared against the
policy's own `noul` threshold instead. Every `Deliberate` fixture's inclusion set
contains the owner, an adversary, and a ruling authority; every fixture's
inclusion set contains the owner; and a `Direct` fixture's inclusion set contains
no judge, the test suite being that mode's only gate.
