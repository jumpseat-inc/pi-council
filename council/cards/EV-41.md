## Intent

Built and run before the mechanism lands, so it starts red — a Council command
without an end-to-end falsifier is a defect. The card must name both forcing
paths: a stub-child mode (`STUB_MODE=finish_error`) that emits the bare string
`Provider finish_reason error` as its `errorMessage`, and a harness that fails
a parent turn's provider once in a scratch session, in both the TUI and `-p`
branches. The existing `error` stub mode emits `Provider returned 502:
upstream unavailable`, which already matches pi's retryable pattern and so does
not exercise the intake's class.
