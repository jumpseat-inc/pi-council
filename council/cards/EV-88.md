## Intent

The end-to-end falsifier for the setup fail-closed arm: the same `/council-setup` run under `gate.mode` off and under `gate.mode` active with an unreachable decisions endpoint must both recommend `Default`, print a non-empty question set, and write zero custom seats or emphasis notes; the two variants' basis strings must differ (`off` vs `gate call failed: <reason>`). A deliberately injected seat-emphasis write makes the phase fail.

## Acceptance

Both variants print the recommendation literal `Default` and a non-empty question set; the two variants' basis strings differ — the `off` variant emits the literal `off`, the `active`/unreachable variant emits `gate call failed: <reason>`; zero seat-emphasis files and zero new agent files are created; a deliberately injected seat-emphasis write makes the phase fail; the `active` variant exercises the real `runSetupGate` fail-closed path (not a stub).
