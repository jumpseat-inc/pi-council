## Intent

One HTTP call carries the whole question set, answers come back in parallel and
in isolation, and the transport sits behind a narrow injected interface so the
endpoint can be swapped without touching the decision function. The credential
is the account's existing OpenRouter key resolved through the engine's existing
resolver; no new secret is introduced and no second provider is involved. The
model id is pinned, because a versioned id is what confidence floors were tuned
against, and the response's reported versioned model is logged so a version
change is visible rather than silent.

The request and response shapes are pinned by live capture, so an implementer
does not have to rediscover them. The body is `{model, state, questions}`, where
`questions` is a record keyed by question id and each entry carries `type`
(`choice`, `noul`, or `score`), `instructions`, and `criteria` — a record of
option to description for `choice` and `noul`, and an ordered array of criterion
strings for `score`. The response carries `answers` keyed by question id,
`usage` with `input_tokens`, `output_tokens` and `cost`, the `provider`, and a
generation `id` beginning `gen-dec-`; its `model` field reports the exact
versioned model that answered (`typesafe/jev-1.13-20260917` for the
`typesafe/jev-1.13` pin), which is the version this card logs.

The failure posture is fail-closed and is the reason this card can be `Ready`. A
live `POST /api/v1/chat/completions` with this model returns `400` carrying the
refusal string `typesafe/jev-1.13 is a decisions model and cannot be used with
the chat/completions endpoint. Use the /api/alpha/decisions endpoint instead.`,
so there is no fallback worth building: a refusal, a timeout, or any non-2xx
resolves the card to `Deliberate` and records the failure reason verbatim.
Nothing here may ever call the `chat/completions` path with this model, and
nothing may treat a missing answer as a negative answer.

## Acceptance

Exactly one POST per call, to the decisions path, with the pinned model id; a
`400` decisions-model refusal, a timeout, and a non-2xx each resolve to
`Deliberate` with the reason string recorded verbatim; an unanswered question is
absent from the answers rather than coerced to a value; the default suite makes
no network call; and the live call is reachable only behind the repository's
existing opt-in integration gate.
